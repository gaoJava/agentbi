# InsightPilot AgentBI 部署与用户手册

## 环境要求

- Windows 10/11（完整比赛演示推荐）或 Linux/macOS（AgentBI 服务）
- Python 3.11+、Node.js 18+、Java 17、Docker Desktop/Engine
- 固定版本 Apache Superset 与 SuperSonic 源码或构建产物
- 至少 8 GB 可用内存和 10 GB 可用磁盘

## 安装

Windows：

```powershell
.\delivery\install.ps1 -UseBundledDemoCredentials
```

Linux/macOS：

```bash
chmod +x delivery/install.sh
./delivery/install.sh
```

安装脚本创建 `.venv`、安装 AgentBI 与开发验收依赖、初始化数据库，并检查外部依赖。完整演示默认从 AgentBI 同级目录查找 `superset-main` 和 `supersonic-stable`。

## 安全配置

复制 `delivery/env.example` 为仅本机保存的 `.env`，填写运行时凭据。不要把 `.env` 加入提交包。生产环境必须替换演示账号、使用 32 位以上随机服务密钥，并通过 HTTPS 反向代理暴露服务。

## 启动

仅启动原生工作台：

```powershell
.\scripts\start-workbench.ps1
```

完整集成演示：

```powershell
.\scripts\start-demo.ps1 -UseBundledDemoCredentials
```

访问地址：工作台 `http://127.0.0.1:8090/app`，API 文档 `http://127.0.0.1:8090/docs`，Superset `http://127.0.0.1:8088`，SuperSonic `http://127.0.0.1:9080`。

## 操作闭环

1. 在“数据源”同步 Superset Dataset。
2. 在“语义模型”创建智能草稿，审核维度、指标和聚合后发布。
3. 在“仪表盘管理”创建图表并加入目标仪表盘。
4. 在“下钻配置”绑定真实 Superset 图表和下钻维度路径。
5. 在“分析工作台”点击图表的“AI 分析”，输入自然语言问题。
6. 从结果选择数据项进入“下钻分析”，逐层生成新图表并分析。
7. 生成分析报告，AI 辅助完善后保存、下载 Word 或打印 PDF。

## 模型配置与测试

在“语义模型 -> 模型服务配置”新增 OpenAI-compatible 服务，填写 Base URL、模型名和 API Key。保存前系统会执行 Chat Completions 兼容性测试。随后在“SuperSonic LLM 增强”分别选择问答意图解析、智能建模和报告生成模型，点击“应用设置”。

测试顺序：先用智能建模生成一个新 Dataset 草稿；再在图表上询问“第一名比第二名高多少，占第二名的百分之几”；最后在报告页点击 AI 辅助生成。三处均成功且后台审计显示对应角色模型，才算路由生效。

## 故障恢复

- 模型连接失败：检查 Base URL 是否以供应商要求的 `/v1` 或 `/v4` 结尾、模型名是否为部署名、API Key 权限和服务端公网连接。
- 查询无数据：扩大时间范围，确认 Dataset 确实包含该年份的数据。
- 图表按钮无响应：重新点击图表 AI 分析以刷新 Chart ID，检查浏览器控制台与 AgentBI 日志。
- 下钻层为空：确认图表已绑定真实 Chart/Dataset，路径字段存在于同一语义模型。
- 保存报告后内容未更新：确认保存接口成功；“已发布”只代表业务状态，不是保存开关。
- 完整环境异常：执行 `scripts/stop-demo.ps1` 后重新启动；保留数据卷，不要删除用户数据。
