### M8：Superset 分析画布融合（进行中）

当前进展：经营总览默认承载真实 Superset 仪表盘，本地静态画布仅作为故障降级。
管理员可从 Superset API 同步仪表盘元数据、图表数量和发布状态，并选择首页仪表盘；
当前已同步 9 个真实仪表盘，`Sales Dashboard`（10 个图表）设为经营总览。查看态使用
`standalone=3` 避免重复导航，管理员可切换编辑态；未启动时的加载、重试和本地降级也已验证。
本地 Superset CSP 仅允许 8090 回环来源嵌入。剩余工作是把本地登录会话嵌入升级为
生产级 Guest Token 流程，并稳定同步筛选器、时间范围和选中数据点。

验收标准：

- [x] 中间区域可加载 Superset 仪表盘，产品导航与 Superset 内部导航不重复抢占空间。

- [x] 统一中文产品文案、空状态、加载状态和上游不可用提示。
- [ ] AgentBI 能稳定获取当前仪表盘、图表、筛选器、时间范围和选中数据点。
- [ ] Superset 不直接暴露在公网；嵌入令牌、CSRF 和允许域均由服务端控制。
