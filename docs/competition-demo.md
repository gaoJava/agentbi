# AgentBI 大赛 5 分钟演示脚本

## 演示前检查

```powershell
.\scripts\start-demo.ps1 -UseBundledDemoCredentials
.\scripts\verify.ps1
```

打开 `http://127.0.0.1:8088`，登录 Superset，进入 Sales Dashboard。确认右下角显示“AI 洞察·已连接”。演示前不要提前展开审计详情，避免第一屏信息过多。

## 0:00–0:45：一句话定位与架构

讲解词：

> InsightPilot 不是在大屏旁边简单放一个聊天框，而是让 Agent 感知当前大屏、语义模型、时间和筛选条件；所有问题都经过 Superset 登录身份、AgentBI 安全策略和 SuperSonic 受治理语义查询，最终返回可核验的数据证据。

快速指出三层：Superset 负责交互和身份，AgentBI 负责工作流/安全/报告，SuperSonic 负责指标语义和查询。

## 0:45–1:45：屏幕上下文与首轮分析

1. 点击右下角“AI 洞察”。
2. 指出“大屏 5、模型 1、最近7天、筛选数”等上下文标签。
3. 点击快捷问题“alice 停留时长”，提交。
4. 展示 6 行结果、执行步骤和查询耗时。

讲解重点：浏览器没有提交角色和 SQL；角色由 Superset 后端会话注入，原始 SQL只保留指纹。

## 1:45–2:40：连续追问

输入：

```text
哪一天停留时长最高？
```

指出绿色会话编号保持不变，第二轮返回聚合后的 1 行结果。讲解 AgentBI 会话与 Superset 用户绑定，其他用户不能拿会话号读取其上下文。

## 2:40–3:35：下钻与报告

1. 点击“基于首行结果继续下钻”。
2. 展示系统自动把首行的维度和值带入下一问题。
3. 展示“关键观察”和“建议动作”。
4. 点击“下载可审计 Markdown 报告”，说明报告包含结论、建议、查询编号、模型、时间、行数、耗时、SQL 指纹、生成时间和来源大屏回链。

## 3:35–4:25：稳定性与安全

展示“数据证据与审计信息”，并说明：

- WEB_PAGE/外部链接候选不会执行，只接受带受治理 `querySQL` 的语义候选。
- 超时、上游异常和超大结果都有边界；结果默认最多 500 行。
- 请求有 API Key、CSRF、角色校验、每用户限流和幂等保护。
- 审计日志只记录追踪号、路径、状态和耗时，不记录问题、令牌、原始 SQL 或完整结果。

## 4:25–5:00：总结与创新点

结束语：

> 这个方案把 BI 从“看图—自己找原因”升级为“基于当前屏幕发起受治理分析—继续追问下钻—生成可回溯报告”。它保留 Superset 和 SuperSonic 各自的开源优势，同时用 AgentBI 编排层解决身份、安全、稳定性和证据链问题。

## 异常恢复备用演示

如果图表加载较慢：直接打开 AI 洞察，屏幕上下文识别与问答不依赖全部图表动画完成。

如果 SuperSonic 某个自然语言问题歧义：使用已验证问题“alice 停留时长”，不要临时改成未配置的业务口径。

如果浏览器演示异常：

1. 访问 `http://127.0.0.1:8090/health` 展示编排器健康。
2. 访问 `http://127.0.0.1:8090/docs` 展示类型化接口。
3. 执行 `.\scripts\verify.ps1 -SkipFrontend` 展示安全与协议回归。
4. 重新加载 Superset Dashboard；扩展会自动重新挂载，不需要重新登录。
